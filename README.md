# Eslabong 한국어 보완 · 유물 프리셋

[최신 릴리즈 다운로드](https://github.com/zhtjstod-cell/eslabong-korean-mods/releases/latest)

릴리즈의 **Eslabong-Korean-Relic-Mods.zip**을 받으세요. GitHub가 자동으로 제공하는 `Source code (zip)`은 사용자용 설치 패키지가 아닙니다.

두 기능을 선택해서 설치하는 비공식 설치형 모드입니다. 현재 확인한 게임에는 외부 모드를 읽는 로더가 없으므로, `mods` 폴더에 복사하는 것만으로 적용되지는 않습니다. 설치기는 필요한 게임 리소스만 수정합니다.

## 설치

1. 게임을 저장하고 완전히 종료합니다.
2. 압축을 원하는 폴더에 모두 풉니다. 게임 폴더 안에 풀 필요는 없습니다.
3. `EslabongMods.exe`를 실행합니다.
4. `eslabong.exe`와 `eslabong.pck`가 있는 게임 폴더를 선택합니다.
5. 원하는 모드를 체크하고 **선택한 구성 적용**을 누릅니다.

Windows 64비트용입니다. Python, PowerShell 명령, 별도 글꼴 설치, 인터넷 연결은 필요하지 않습니다. 게임 폴더 쓰기 권한과 게임 데이터 크기의 약 두 배에 해당하는 여유 공간이 필요합니다. 서명되지 않은 개인 제작 실행 파일입니다. 백신을 끄거나 보안 기능을 해제할 필요는 없습니다.

자동 탐색은 실행 위치와 상위 폴더, 설치기 위치와 상위 폴더, Steam 레지스트리에 등록된 라이브러리, 개발 환경의 기본 게임 경로를 확인합니다. 못 찾으면 폴더를 직접 선택하면 됩니다. `변경 없이 검사`로 적용 가능 항목을 먼저 확인할 수 있습니다.

게임 업데이트로 모드가 풀렸다면 **같은 설치기를 다시 실행해 적용**하세요. 파일 전체가 달라져도 필요한 함수와 표시 구문이 맞으면 그 부분을 찾아 적용합니다. 설치기가 백그라운드에서 게임 파일을 감시하거나 자동 실행되지는 않습니다. 새로 추가되거나 의미가 바뀐 문장을 자동 번역하지는 않으며, 맞지 않는 번역·표시 구문은 그대로 둡니다. 유물 장착·저장 규칙 자체가 달라 안전을 확인할 수 없으면 유물 모드는 중단합니다.

## 한국어 보완

- 누락 번역, 일부 영어로 남던 설명과 용어, 설명문 표시 경로를 보완합니다.
- 기존 인물과 이후 기본 이름 목록에서 생성되는 인물의 이름·별칭을 한국어에서 한글로 표시합니다.
- 한국어에서는 직업 이름도 한글로 표시합니다. 한국어 이외의 언어에서는 원래 표시를 유지합니다.
- 직접 입력한 이름·별명을 존중합니다. 기존 저장 데이터의 원래 이름과 능력치는 일괄 변경하지 않습니다.
- 이적 제안·알림·드래프트 미리보기·올스타·순위표의 축약 이름·저장한 주전·명예의 전당에서 영어로 남던 이름을 보완합니다. 시설·대회·기술 진화 명칭과 전투 통계의 기술명 표시도 보완합니다.
- 기존 알림은 선수 ID나 이름 필드로 인물을 확인할 수 있는 경우 이름 부분만 화면에서 한글로 표시합니다. 저장된 옛 뉴스의 문장 전체나 목록에 없는 사용자 제작 이름을 다시 번역하는 기능은 아닙니다.
- 팀 전투력·도전 타워 관련 새 미번역 문구 10개를 추가했습니다.
- 시장 표 머리글·선수단 인원 요약·인원별 컵 일정, 록스카 직업명의 잘못 연결된 번역 키를 보완합니다. 파워 발라드·아이언베일 수호대·이너비전 기사단·분노 연합·아콩카과의 이름을 표시 화면에서 한글로 보여 줍니다.
- 대문자·별칭 표기의 이름을 보완하며, 뉴스에 등장하는 현재 선수는 원래 이름이나 ID를 바꾸지 않고 화면에 한글로 표시합니다.
- 보완 번역과 이름 음역은 GPT가 직접 작성한 기존 작업을 사용했습니다. 게임에 원래 있던 한국어 전체를 새로 번역한 것은 아닙니다.

기존 로컬 한국어 보완 패치가 적용되어 있어도 별도로 삭제할 필요 없이 전환할 수 있습니다.

## 유물 프리셋

선수단 → **주전 저장** 창에서 **유물도 함께 저장·불러오기**를 체크합니다.

- 체크하고 저장/덮어쓰기: 주전 다섯 명과 각 인물의 유물 두 칸을 함께 기록합니다.
- 체크하고 불러오기: 저장한 각 인물에게 당시 유물을 다시 장착합니다. 다른 보유 인물이 착용하고 있으면 그 인물에게서 옮깁니다.
- 체크 해제: 게임의 기존 주전 저장/불러오기 방식으로 동작하며 유물을 움직이지 않습니다.
- 체크 여부와 유물 기록은 해당 캠페인 저장에 함께 남습니다.

**기존 슬롯에는 유물 기록이 없습니다.** 원하는 장비를 착용한 뒤 체크하고 슬롯을 한 번 덮어써 주세요. 체크를 끄고 슬롯을 덮어쓰면 그 슬롯의 유물 기록도 제거됩니다.

### 아이템 안전 규칙

- 유물 종류가 아니라 보유한 **개별 아이템의 고유 ID**를 저장합니다.
- 같은 종류의 다른 사본으로 임의 대체하지 않습니다. 개별 수치와 소유 이력은 그대로 유지합니다.
- 판매·분실·거래 등록·보관 제한, 잠긴 슬롯, 장착 불가 유물은 건너뜁니다. 없어진 유물을 생성하거나 복사하지 않습니다.
- 건너뛴 칸의 기존 장비는 가능한 경우 유지합니다. 다른 칸에서 그 아이템을 불러오는 경우에는 그쪽으로 이동할 수 있습니다.
- 비워 두고 저장한 칸은 불러올 때도 비우고, 벗긴 유물은 보관함으로 돌려놓습니다.
- 전설 장착 한도, 동일 유물 중복 장착 제한 등 게임 규칙을 지킵니다.
- 유물 적용 중 규칙 충돌·데이터 불일치가 발생하면 전체 유물 변경을 되돌리고 주전 변경도 적용하지 않습니다.
- 유물 포함 불러오기는 기존의 선수 배치 전용 **되돌리기** 버튼을 제공하지 않습니다. 이전 구성을 되돌리려면 다른 슬롯에 미리 저장하세요.

## 구성 변경 / 제거 / 백업

게임 종료 후 설치기를 다시 열고, 설치할 모드만 체크해 적용합니다. 모두 해제하고 적용하면 이 모드가 수정한 표시·프리셋 동작을 원래대로 돌립니다. 다른 모드의 알 수 없는 수정은 덮어쓰지 않습니다. 설정 화면의 체크박스는 **이번에 적용할 구성**이며, 항상 두 항목이 체크된 상태로 시작합니다.

게임 실행 파일, Steam 관련 파일, 저장 파일은 설치기가 수정하지 않습니다. 게임 데이터는 변경 직전 전체를 `KoreanPatchBackup/mods-날짜-고유값/eslabong.pck`에 백업합니다. 백업은 자동 삭제하지 않습니다. 게임 업데이트 후에는 예전 게임 데이터 전체 백업을 덮어쓰지 마세요.

Steam 업데이트나 파일 무결성 검사로 게임 데이터가 교체되면 패치가 풀릴 수 있습니다. 예전 설치 기록이 남아 있어도 실제 패치가 유지된다는 뜻은 아닙니다. 같은 설치기를 다시 실행하세요. 이전 설치 이후 파일 변경이 감지되면 안내하고 현재 데이터로 재검사합니다.

모드를 제거해도 저장 파일의 추가 프리셋 기록이나 사용되지 않는 보조 리소스는 안전을 위해 남습니다. 장착 중인 유물은 그대로 유지됩니다. 설치 중간에 문제가 생기면 게임을 실행하지 말고 설치 결과와 백업 위치를 확인하세요.

## 검증 범위

- 게임과 분리된 동일 엔진 테스트에서 유물 관련 2,164개 검사 통과. 1,000가지 장착 순열, 반복 적용, 순환 교환, 판매/잠금/제약, 실패 시 복구, 실제 저장·불러오기 코드 연결, 저장 파일 직렬화 확인.
- 기존 설명문/이름 번역 및 한국어→영어→한국어 전환, 새 이름의 한글 글리프 포함 여부 확인.
- 추가 이름·명칭 표시를 별도 엔진에서 검사했습니다. 실제 축약 이름·이적 요약·이름 목록·전투 통계 함수, 언어 전환, 직접 지정한 이름, 원래 데이터 보존을 포함합니다.
- 설치기에서 두 모드의 네 가지 조합, 제거, 반복 적용, 기존 한국어 패치 전환, 불일치 데이터 보호, 실행 중 게임 보호 검증.
- 업데이트된 클린 데이터 및 새 함수 추가·줄 번호 이동·팝업 표시 변경을 가정한 데이터에서 자동 매칭과 제거를 검증했습니다. 게임에 새로 포함된 한국어는 모드 제거 시에도 남깁니다.
- 실제 플레이 화면의 배치와 사용자 저장 파일로 플레이하는 검증은 별도입니다. 게임 내 주전 저장 창에서 확인해 주세요.

게임 본체·원본 스크립트 전체·게임 리소스 복호화 키·유료 글꼴은 배포하지 않습니다. 실행 파일에는 설치 도구와 번역 데이터, 직접 작성한 모드 코드, 작은 변경 데이터만 포함됩니다.

## 소스

설치기, 직접 작성한 모드 코드, 번역 데이터 및 변경 데이터는 `source/`에 있습니다. [빌드 안내](BUILD.md)와 [릴리즈 안내](RELEASE_NOTES.md)를 참고하세요. 문제를 제보할 때는 개인 정보가 보이지 않도록 설치 결과와 해당 화면을 첨부해 주세요. 게임 본체나 개인 저장 파일 전체를 공개 이슈에 올리지 마세요.
