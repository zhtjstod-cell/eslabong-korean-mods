# Eslabong 한국어 보완 · 유물 프리셋 모드 로더

한글 이름·직업명·미번역 보완과 유물 프리셋 두 가지를 선택하는 비공식 모드 로더입니다. 게임 원본을 덮어쓰지 않고 실행할 때 모드를 불러옵니다.

## 다운로드 및 실행

[최신 릴리즈](https://github.com/zhtjstod-cell/eslabong-korean-mods/releases/latest)에서 **Eslabong-Korean-Relic-Mod-Loader-v1.3.0.zip**을 받으세요. GitHub의 `Source code` 압축은 실행용이 아닙니다.

1. 게임을 저장하고 완전히 종료합니다.
2. ZIP 전체를 원하는 폴더에 풉니다. **EXE와 함께 들어 있는 `mods` 폴더도 꼭 필요합니다.** 게임 폴더 안이나 밖 모두 가능합니다.
3. `EslabongCommunityLoader.exe`를 실행하고, `eslabong.exe`와 `eslabong.pck`가 있는 게임 폴더를 선택합니다.
4. 원하는 두 기능을 선택한 뒤 **모드로 게임 실행**을 누릅니다.
5. 다음부터 같은 EXE를 더블 클릭하면 저장한 선택으로 실행합니다. 게임이나 모드 파일이 바뀐 경우에만 자동으로 다시 준비합니다.

Windows 64비트용입니다. Python·PowerShell 명령·별도 글꼴 설치는 필요하지 않습니다. 실행기 폴더에 쓰기 권한과 캐시를 만들 여유 공간이 필요합니다. 처음 준비는 PC와 게임 데이터에 따라 시간이 걸릴 수 있습니다. 서명되지 않은 개인 제작 프로그램이며, 백신이나 보안 기능을 끄지 마세요.

설정 변경은 **Shift를 누른 채 EXE를 열고 설정 창이 나타날 때까지 유지**하거나 `EslabongCommunityLoader.exe --settings`로 실행하세요. **실행하지 않고 준비 / 검사**로 게임을 켜지 않고 확인할 수도 있습니다. 선택 상태는 다음 실행에도 유지됩니다.

### Steam 플레이 버튼으로 실행

설정 창의 **Steam 플레이 버튼 연결용 문구 복사**를 눌러 Steam → Eslabong 속성 → 일반 → 실행 옵션에 붙여 넣으세요. 기존 옵션은 먼저 보관하세요. 로더는 Steam 설정을 자동 변경하지 않습니다.

연결하지 않은 Steam 플레이 버튼이나 원본 `eslabong.exe`는 외부 모드를 읽지 않습니다. 직접 실행이 Steam을 통한 원본 실행으로 돌아가는 환경에서도 위 연결 방법을 사용하세요. Steam을 로그인한 상태로 켜 두세요. 게임의 인증·온라인 검사는 원래 코드 그대로 사용합니다.

## 업데이트와 기존 설치판 전환

이 로더로 실행하면 현재 게임과 모드의 내용을 확인합니다. 변경이 없으면 캐시를 재사용하고, 업데이트됐으면 현재 데이터에서 연결 위치를 다시 찾습니다. 매번 설치 버튼을 누르거나 원본 PCK를 다시 수정할 필요가 없습니다. 백그라운드 감시는 하지 않습니다.

이전에 `EslabongMods.exe`로 패치했다면 먼저 제거하지 않아도 사용할 수 있습니다. **다만 이미 원본에 적용된 수정까지 로더가 지우지는 않습니다.** 깨끗한 원본으로 전환하려면 Steam 파일 무결성 검사 후 로더를 사용하세요. 예전 버전의 PCK 백업 전체를 새 게임 위에 덮어쓰지 마세요.

이미 매칭되는 번역은 재사용하지만 새 원문을 자동 번역하지는 않습니다. 필요한 API가 사라지거나 코드 구조가 크게 바뀌면 안전하게 중단할 수 있으며 모든 미래 업데이트의 호환성을 보장하지는 않습니다.

## 한국어 보완

번역 키가 바뀌어도 같은 분류 안에서 원문과 번역이 유일하게 대응하면 기존 번역을 재사용합니다. 줄바꿈·공백 변화도 처리하며, 뜻이 바뀐 문장이나 번역이 여러 가지인 원문은 추측하지 않습니다. 업데이트에서 새로 제공한 한국어와 다른 언어 파일은 보호합니다. 화면 함수 일부가 바뀌면 그대로 남은 표시 구문은 개별적으로 적용합니다.

- 누락 번역, 일부 영어로 남던 설명과 용어, 설명문 표시 경로를 보완합니다.
- 새 챔피언 이름 11개 표기, 번역 키가 없는 배경 7개와 대사 9개를 추가했습니다. 기존 대사 8개와 해상도·육성 대회·철문 관련 18개 항목도 보완했습니다. 챔피언 설명은 검토한 원문이 일치할 때만 번역하므로 내용이 달라진 문장을 억지로 바꾸지 않습니다.
- 기존 인물과 이후 기본 이름 목록에서 생성되는 인물의 이름·별칭을 한국어에서 한글로 표시합니다.
- 한국어에서는 직업 이름도 한글로 표시합니다. 한국어 이외의 언어에서는 원래 표시를 유지합니다.
- 직접 입력한 이름·별명을 존중합니다. 기존 저장 데이터의 원래 이름과 능력치는 일괄 변경하지 않습니다.
- 이적 제안·알림·드래프트 미리보기·올스타·순위표의 축약 이름·저장한 주전·명예의 전당에서 영어로 남던 이름을 보완합니다. 시설·대회·기술 진화 명칭과 전투 통계의 기술명 표시도 보완합니다.
- 기존 알림은 선수 ID나 이름 필드로 인물을 확인할 수 있는 경우 이름 부분만 화면에서 한글로 표시합니다. 저장된 옛 뉴스의 문장 전체나 목록에 없는 사용자 제작 이름을 다시 번역하는 기능은 아닙니다.
- 최신 게임의 전투 HUD·도전의 탑·환생 성장 재설정·외형 편집·미라주 직업 관련 미번역 등 125개 항목을 추가·보완했습니다.
- 새 공통 이름 표시 경로를 통해 시장·선수단 카드의 한글 이름을 보완합니다. 기본 게임의 Shiny 식별 표시와 언어별 폰트 전환은 유지합니다.
- 시장 표 머리글·선수단 인원 요약·인원별 컵 일정, 록스카 직업명의 잘못 연결된 번역 키를 보완합니다. 파워 발라드·아이언베일 수호대·이너비전 기사단·분노 연합·아콩카과의 이름을 표시 화면에서 한글로 보여 줍니다.
- 대문자·별칭 표기의 이름을 보완하며, 뉴스에 등장하는 현재 선수는 원래 이름이나 ID를 바꾸지 않고 화면에 한글로 표시합니다.
- 보완 번역과 이름 음역은 GPT가 직접 작성한 기존 작업을 사용했습니다. 게임에 원래 있던 한국어 전체를 새로 번역한 것은 아닙니다.

기존 로컬 한국어 보완 패치가 적용되어 있어도 별도로 삭제할 필요 없이 전환할 수 있습니다.

## 유물 프리셋

선수단 → **주전 저장** 창에서 **유물도 함께 저장·불러오기**를 체크합니다.

저장·조회·주전 확정 호출과 안내 라벨을 찾아 연결합니다. 화면 함수명·지역변수명이나 저장 구문의 일부가 바뀌어도 호출 관계가 유지되면 다시 연결하며, 장착·해제는 현재 게임의 함수를 그대로 사용합니다. 필요한 API가 사라지거나 연결이 모호한 경우에는 변경 전에 중단합니다.

- 체크하고 저장/덮어쓰기: 주전 다섯 명과 각 인물의 유물 두 칸을 함께 기록합니다.
- 체크하고 불러오기: 저장한 각 인물에게 당시 유물을 다시 장착합니다. 다른 보유 인물이 착용하고 있으면 그 인물에게서 옮깁니다.
- 체크 해제: 게임의 기존 주전 저장/불러오기 방식으로 동작하며 유물을 움직이지 않습니다.
- 체크 여부와 유물 기록은 해당 캠페인 저장에 함께 남습니다.

**기존 슬롯에는 유물 기록이 없습니다.** 원하는 장비를 착용한 뒤 체크하고 슬롯을 한 번 덮어써 주세요. 체크를 끄고 슬롯을 덮어쓰면 그 슬롯의 유물 기록도 제거됩니다.

### 아이템 안전 규칙

- 유물 종류가 아니라 보유한 **개별 아이템의 고유 ID**를 저장합니다.
- 같은 종류의 다른 사본으로 임의 대체하지 않습니다. 개별 수치와 소유 이력은 그대로 유지합니다.
- 판매·분실·거래 등록·보관 제한, 잠긴 슬롯, 장착 불가 유물은 건너뜁니다. 없어진 유물을 생성하거나 복사하지 않습니다.
- 건너뛴 칸의 기존 장비는 가능한 경우 유지합니다. 다른 칸에서 그 아이템을 불러오는 경우에는 그쪽으로 이동할 수 있습니다.
- 비워 두고 저장한 칸은 불러올 때도 비우고, 벗긴 유물은 보관함으로 돌려놓습니다.
- 전설 장착 한도, 동일 유물 중복 장착 제한 등 게임 규칙을 지킵니다.
- 유물 적용 중 규칙 충돌·데이터 불일치가 발생하면 전체 유물 변경을 되돌리고 주전 변경도 적용하지 않습니다.
- 유물 포함 불러오기는 기존의 선수 배치 전용 **되돌리기** 버튼을 제공하지 않습니다. 이전 구성을 되돌리려면 다른 슬롯에 미리 저장하세요.


## 파일 구성과 제거

- `EslabongCommunityLoader.exe`: 공개판 전용 실행기.
- `mods/KoreanSupplement`: 한국어 보완·이름 한글화.
- `mods/RelicPresets`: 유물 프리셋.
- `mods/EslabongCommunityLoader`: 실행 후 만들어지는 공개판 설정·캐시.
- `source`, `licenses`: 공개 소스 및 라이선스.

개인용 실행기와 공개판의 설정·캐시는 서로 분리됩니다. 이 배포에는 한글 보완과 유물 프리셋 이외의 추가 기능을 넣지 않았습니다. 다른 도구로 원본에 이미 적용한 모드까지 자동으로 제거하는 기능은 아닙니다.

게임 종료 후 설정에서 해제하면 해당 기능이 다음 모드 실행에서 꺼집니다. 특정 모드 폴더를 제거해도 다음 실행에서 그 기능을 끕니다. 모두 제거하려면 Steam 실행 옵션에 연결한 문구를 먼저 지우고 공개판 EXE와 두 모드 폴더, `mods/EslabongCommunityLoader`, `EslabongCommunityLoader.location.json`을 제거하세요. 개인용 또는 다른 모드 폴더는 지우지 마세요.

로더는 원본 EXE/PCK와 세이브를 직접 수정하지 않습니다. 게임이 시작된 뒤의 저장은 게임 원래 방식이며, 유물 프리셋 기록은 캠페인에 저장됩니다. 예전 설치판이 수정한 원본을 복구하려면 게임의 파일 무결성 검사를 별도로 이용하세요.

## 검증과 문제 확인

업데이트·모드 변경 감지, 선택 상태 유지, 캐시 손상 시 재준비, 중복 준비 차단, 한글·공백 경로를 검사합니다. 실제 엔진의 격리 프로필에서 원본 팩과 모드 팩의 로드 순서·내용을 확인하며, 이 검사는 실제 세이브 로드나 온라인 제출을 실행하지 않습니다. 플레이 화면 전체의 시각 검증을 뜻하지 않습니다.

유물은 기존 2,186개 검사와 1,000가지 장착 순열 검증을 사용합니다. 함수명·지역변수명 변경, 저장 구문의 변경, 필수 API 제거·모호한 연결에 대한 검사도 포함합니다.

문제가 있으면 오류 문구와 `mods/EslabongCommunityLoader/cache/build-…/preflight.log`를 확인하세요. **cache 안의 생성 파일은 재배포하지 마세요.** 본인 게임에서 생성한 리소스와 실행 파일 사본이 들어 있습니다. 게임 종료 후 캐시만 지우면 다음 실행에서 다시 준비합니다.

게임 본체·원본 스크립트 전체·개인 세이브·복호화 키·유료 글꼴은 배포하지 않습니다. 소스 빌드는 [BUILD.md](BUILD.md)를 참고하세요.
